### Overview
A curated collection of JavaScript bookmarklets designed for high-performance browser automation. This repository provides specialized tools for social media management, developer productivity, and workflow enhancement.

### Deployment & Automation
The project features an integrated CI/CD pipeline:
- **Engine**: Custom Python generator parsing the repository structure.
- **Frontend**: A performance-optimized, high-contrast interactive gallery.
- **Automation**: GitHub Actions automatically rebuild the studio on every script update.

### Installation

#### 01. Studio Deployment (Recommended)
Visit the **[Bookmarklet Studio](https://NotNahid.github.io/bookmarklet/)** and drag the desired tool directly to your browser's bookmarks bar.

#### 02. Source Integration
1. Review the source code in the `src/` directories.
2. Create a new browser bookmark.
3. Map the JavaScript source to the bookmark URL.
